# Фронтенд диспетчера

React 19 + Vite + Tailwind 4 + Leaflet. Карта маршрутов, списки бригад и заявок, расписание бригад,
панель объяснений, события дня и сравнение с базовым вариантом. Данные берёт из API бэкенда (`/api`).

```bash
npm ci
npm run dev     # http://localhost:5173, запросы /api проксируются на http://127.0.0.1:8000
npm run build   # сборка в dist/; её раздаёт бэкенд, папка хранится в репозитории
```

Нужен Node.js 20.19+. Запуск всего приложения — в корневом README.
